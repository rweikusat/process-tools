process-tools
=============

A collection of tools for process configuration and background process
startup. 

Running `make deb` in the top-level source directory can be used to
build a Debian package.

New For 0.2
-----------

- have-locks -- check if locks to a set of file are held
- lock -- exec a command with a set of POSIX record locks held
- pause -- invoke pause(2)
